# Claude Session HQ

Claude Code 세션 여러 개를 동시에 굴리면서, 터미널 탭을 오가지 않고 브라우저 한 화면에서 일하기 위한 로컬 도구입니다.

- **작업 보기**: 왼쪽 세션 목록에서 고르면 오른쪽에 그 세션의 대화가 채팅 화면으로 열리고, 아래 입력칸으로 바로 말합니다. Orca에서 띄운 세션도 옮기지 않고 그대로 대화합니다. 웹에서 연 세션은 터미널 화면으로도 볼 수 있습니다
- **새 세션**: 폴더, 업무, 첫 지시를 골라 브라우저에서 바로 시작합니다
- **되감기**: 대화 화면에서 Esc를 두 번 누르거나 '되감기' 버튼을 누르면, 터미널의 Claude Code처럼 앞서 보낸 말을 골라 그 전으로 대화(와 코드)를 되돌립니다. 그때 보낸 말은 입력칸으로 돌아옵니다(웹에서 띄운 세션만)
- **btw**: 메인 작업을 시켜 둔 동안 옆 칸에서 Claude Code의 `/btw`로 궁금한 것을 묻습니다. 하던 일을 끊지 않고 원래 대화에도 남지 않으며, 질문·답은 HQ에 남습니다(웹에서 띄운 세션만)
- **세션 유지**: 웹에서 연 세션은 전용 tmux 안에서 돕니다. 브라우저를 닫거나 서버가 재시작돼도 살아 있고, 맥을 재부팅하면 같은 명령(`claude <원래 옵션> --resume <대화 ID>`)으로 자동 복구됩니다
- **한눈에 보기**: 열린 세션 수, 세션별 상태(작업중 / 내 차례 / 승인 필요 / 쉼), 나를 기다리는 세션을 모아 보여 줍니다
- **가상 사무실**: 업무별 보기는 업무마다 방이 하나씩 있는 픽셀 사무실입니다. 세션은 책상 앞 사람으로 보이고, 나를 기다리는 사람은 손을 들고 말풍선을 띄웁니다. 책상을 끌어 자리나 방(업무)을 옮깁니다
- **업무 단위**: 업무를 만들고 세션을 방으로 끌어다 놓아 묶습니다. 업무마다 "박과장 답 기다림" 같은 사람 대기를 적어 둡니다
- **지난 대화 다시 열기**: 웹 안의 Claude에게 "조신혜 대리랑 ssh 연결했던 거 찾아서 열어줘"처럼 말하면, Claude가 대화 기록을 뒤져 찾은 뒤 웹에 그 대화를 이어 엽니다(`skills/hq-open`)
- **모두 재시작**: 전역 CLAUDE.md·.zshrc를 바꾼 뒤 환경설정 → 세션의 "모두 재시작"을 두 번 누르거나 Claude에게 "웹 재시작"이라고 하면, 웹 세션을 모두 끄고 같은 대화로 다시 띄웁니다(`skills/hq-restart`)
- **핀·메모·btw**: 대화 옆 칸에서 Claude의 핀보드(할 일·결정할 것), 내 메모, btw를 위아래로 펼쳐 봅니다. 사이 경계를 끌어 높이를 바꿉니다. 메모는 직접 적거나 Claude에게 "이거 메모해 둬"라고 시킵니다(`skills/hq-memo`). F4에서 메모를 모아 봅니다
- **업무로 들어가기**: 세션의 Claude에게 "○○ 업무로 가", "어울리는 이름으로 업무 만들어서 들어가 있어"라고 말하면 Claude가 스스로 업무(사무실 방)에 들어갑니다(`skills/hq-task`)
- **Claude끼리 협업**: 세션의 Claude에게 "너를 복제해서 하나 더 만들어 두고 이름은 ○○로", "△△ 세션한테 물어봐"라고 말하면, Claude가 웹에 세션을 띄우거나 복제하고 이름을 붙이며, 다른 세션과 메시지를 주고받습니다(`skills/hq-team`)
- **Orca에서 옮기기**: Orca에서 띄운 세션은 버튼 하나로 웹으로 옮깁니다. Orca 쪽 Claude를 끝내고 같은 대화를 원래 옵션 그대로 이어 띄웁니다

기본으로는 이 맥에서만 열립니다. 사내망의 다른 PC에서 쓰려면 아래 **사내망 접속**을 켭니다.

## 설치

macOS, Node 20 이상, tmux가 필요합니다(`brew install tmux`).

```bash
git clone https://github.com/gyoomun/claude-session-hq.git
cd claude-session-hq
npm install
npm run build
node scripts/install.js
```

`npm install`과 `install.js`는 같은 Node로 실행하세요. 서버를 자동 실행하는 launchd는 Homebrew Node(`/opt/homebrew/bin/node`)가 있으면 그것을 씁니다.

설치하면 세 가지가 바뀝니다.

1. `~/.claude/settings.json`에 훅 6개(UserPromptSubmit, PreToolUse, PostToolUse, PermissionRequest, Stop, PreCompact)를 추가합니다. 다른 도구의 훅은 건드리지 않고, 바꾸기 전 파일을 `settings.json.bak-claude-session-hq`로 남깁니다.
2. `skills/`의 스킬을 `~/.claude/skills`에 링크로 겁니다.
3. 로그인하면 서버가 자동으로 뜨도록 launchd에 등록합니다(`~/Library/LaunchAgents/dev.gyoomun.claude-session-hq.plist`).

그다음 http://127.0.0.1:7420 을 엽니다. 포트를 바꾸려면 `PORT=8000 node scripts/install.js`로 설치합니다.

제거는 `node scripts/install.js --uninstall`입니다. 업무와 배치 기록(`~/.claude/board`)은 남깁니다.

## 사내망 접속

다른 PC에서 `http://<맥 IP>:7420`으로 들어와, 주인 메일로 받은 인증번호로 로그인합니다. 로그인한 기기는 **접속** 화면에서 목록으로 보고 언제든 끊을 수 있습니다. 동료에게 그 자리에서 보여 준 뒤 돌아와서 끊으면, 그 사람은 메일함에 들어갈 수 없으니 다시 들어오지 못합니다.

1. 인증 메일 설정 파일 `~/.claude/board/mail.env`를 만듭니다. Gmail이면 비밀번호 자리에 [앱 비밀번호](https://myaccount.google.com/apppasswords)를 씁니다.
   ```
   SMTP_USER=보내는메일@gmail.com
   SMTP_PASS=앱비밀번호16자리
   MAIL_TO=인증번호받을메일@gmail.com
   ```
   다른 메일 서버는 `SMTP_HOST`, `SMTP_PORT`(기본 465, TLS)를 더 적습니다.
2. 이 맥에서 HQ를 열고 **환경설정 → 접속 → 사내망 접속 켜기**를 누릅니다. 켜고 끄는 것은 이 맥에서만 됩니다.

- 이 맥에서 `localhost`로 여는 화면은 로그인 없이 그대로 쓰입니다
- 로그인하는 사람에게 이름을 묻지 않습니다. 기기 이름은 주인이 전에 붙인 이름 → 사내 IP 명단(`~/.claude/board/ip-names.json`, `{"192.168.60.201": "이름 (부서)"}`) → Windows PC 이름(NetBIOS) → 기기 종류 순으로 자동으로 정해지고, 주인이 접속 화면에서 바꾸면 같은 PC가 다시 로그인할 때도 그 이름으로 보입니다
- 인증번호는 6자리, 10분 동안 유효하고, 5번 틀리면 막힙니다. 메일은 1분에 한 번만 보냅니다. 한 시간에 20번 틀리면 잠깁니다
- 로그인은 30일 동안 안 쓰면 풀립니다. 끊거나 사내망 접속을 끄면 그 기기의 터미널 연결도 바로 끊깁니다
- 웹 화면은 곧 이 맥의 터미널이므로, 인터넷(포트포워딩, 터널)으로는 열지 마세요

## 동작 방식

| 정보 | 어디서 읽나 |
| --- | --- |
| 열린 세션, 작업중인지 쉬는지 | Claude Code가 프로세스마다 쓰는 `~/.claude/sessions/<pid>.json` |
| 세션 제목, 마지막 지시, 마지막 답 | 대화 기록 `~/.claude/projects/*/<sessionId>.jsonl`, 탭 제목 |
| 지금 실행 중인 명령, 승인 대기 | 훅이 남기는 `~/.claude/board/hooks/<pid>.json` |
| 업무, 배치, 사람 대기, 웹 세션 목록 | `~/.claude/board/hq.json` |

- 웹 세션은 전용 소켓(`tmux -L claude-hq`)과 이 저장소의 `tmux.conf`로 돕니다. 상태줄과 tmux 단축키는 꺼져 있어 화면에 드러나지 않습니다.
- 브라우저 터미널은 xterm.js입니다. 출력은 서버가 보내는 이벤트 스트림으로 받고, 키 입력은 POST로 보냅니다.
- 새 세션의 기본 옵션은 `--dangerously-skip-permissions`입니다(`hq.json`의 `claudeArgs`로 바꿀 수 있습니다).

**내 차례와 쉼**: 세션이 일을 마치면 내 차례가 됩니다. '알겠어, 쉬어'를 누르거나 다시 지시를 보내기 전까지 내 차례로 남습니다. 서버가 처음 보는 세션이 이미 30분 넘게 쉬고 있었다면 쉼으로 시작합니다.

## 한계

- macOS 전용입니다.
- 웹 터미널에서 마우스 휠은 tmux 스크롤로 동작하고, 글자를 고르려면 Option을 누른 채 드래그합니다.
- 다른 터미널에서 직접 띄운 세션은 상태만 보이고, 웹에서 열 수는 없습니다. Orca 세션만 옮길 수 있습니다.
- 이벤트 목록은 서버 메모리에만 있어서, 서버를 다시 켜면 비어 있습니다.
