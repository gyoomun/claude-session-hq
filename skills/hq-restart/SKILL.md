# 웹 세션 모두 재시작

웹 세션마다 claude를 바로 끄고(일하는 중이어도), 같은 tmux 이름·같은 옵션으로 `--resume` 해서 이어 띄운다. 로그인 셸로 다시 뜨므로 바뀐 `.zshrc`·전역 `CLAUDE.md`·설정이 반영된다. 대화, 업무 배치, 내 차례·쉼 상태는 그대로다.

1. 먼저 사용자에게 한 줄로 알린다: "웹 세션 모두를 다시 띄웁니다. 이 세션도 끊겼다가 같은 대화로 이어집니다."
2. 실행한다

   ```bash
   curl -s -H 'content-type: application/json' -H 'x-hq: 1' http://127.0.0.1:7420/api/session/restart -d '{}'
   ```

3. 이 명령 뒤에는 다른 도구를 부르지 않고 턴을 끝낸다. 이 세션도 곧 꺼진다

웹 세션이 아닌 것(다른 터미널에서 직접 띄운 Claude)은 건드리지 못한다. 특정 세션만 다시 띄우려면 `{"names":["hq-…"]}`로 tmux 이름을 넘긴다.
